Sesión 5 · intervalos de confianza para dos poblaciones

Comparar dos grupos y decidir si de verdad son distintos

Practica los intervalos de confianza para dos poblaciones: el cociente de varianzas con la tabla F, la diferencia de medias (σ conocidas con z; σ desconocidas con t, casos II y III) y la diferencia de proporciones. Cada intento trae casos nuevos de 2026, tienes 20 minutos y el cronómetro te avisa cuando falten 3.

Lo que vas a usar
Cociente de varianzasSe usa la F de Fisher. Si el intervalo de σ₁²/σ₂² contiene el 1, las varianzas son similares (homogéneas); si no, son diferentes.
Diferencia de mediasσ conocidas: z. σ desconocidas: t. Si las varianzas son similares (caso II) se usa la varianza combinada y n₁ + n₂ − 2 gl; si son diferentes (caso III), g grados de libertad.
Diferencia de proporcionesSe usa z con p₁ y p₂. El error estándar suma las varianzas de las dos proporciones dentro de una sola raíz.
¿Hay diferencia?Si el intervalo de una diferencia (μ₁ − μ₂ o π₁ − π₂) contiene el 0, no hay evidencia de diferencia. Si es todo positivo, el primero es mayor; si es todo negativo, es menor.
Cociente: s₁²/s₂² × 1/F(α/2 ; n₁−1 , n₂−1) ≤ σ₁²/σ₂² ≤ s₁²/s₂² × F(α/2 ; n₂−1 , n₁−1) Caso I (σ conocidas): (x̄₁ − x̄₂) ± z(1−α/2) · √( σ₁²/n₁ + σ₂²/n₂ ) Caso II (σ desc., similares): (x̄₁ − x̄₂) ± t(1−α/2 ; n₁+n₂−2) · sp · √(1/n₁ + 1/n₂) Caso III (σ desc., diferentes): (x̄₁ − x̄₂) ± t(1−α/2 ; g) · √( s₁²/n₁ + s₂²/n₂ ) Proporciones: (p₁ − p₂) ± z(1−α/2) · √( p₁(1−p₁)/n₁ + p₂(1−p₂)/n₂ ) sp = √[((n₁−1)s₁² + (n₂−1)s₂²)/(n₁+n₂−2)]; g = (s₁²/n₁ + s₂²/n₂)² / [ (s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1) ], redondeado al entero más cercano. Redondea z a 2 decimales; t se lee tal cual (3 decimales) y F con 2 decimales.
